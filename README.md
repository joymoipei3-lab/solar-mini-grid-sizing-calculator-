# Solar Mini-Grid Sizing Calculator
A Python-based engineering tool for estimating the key components required in designing a solar photovoltaic (PV) mini-grid system.

## 1. Project Overview

The Solar Mini-Grid Sizing Calculator is a software application developed to simplify the preliminary design and sizing of solar PV mini-grid systems.

The application allows users to enter electrical appliance requirements and calculates estimated energy demand and the corresponding system component sizes.

The project aims to make preliminary solar mini-grid design more accessible, systematic and understandable through software-based calculations.

## 2. Project Objectives

- Develop a Python application for preliminary solar mini-grid sizing.
- Calculate daily electrical energy consumption based on appliance requirements.
- Estimate the required solar PV capacity.
- Determine the battery bank capacity.
- Estimate the appropriate inverter capacity.
- Calculate the required charge controller capacity.
- Explore the integration of an AI-based explainer to help users understand the sizing results.

## 3. Current Features

The current version of the application includes:

- **Appliance Data Entry:** Allows users to enter appliance information and electrical requirements.
- **Energy Demand Calculation:** Estimates total daily energy consumption.
- **Solar PV Sizing:** Estimates the required solar panel capacity.
- **Battery Bank Sizing:** Calculates the estimated battery storage requirements.
- **Inverter Sizing:** Determines the estimated inverter capacity.
- **Charge Controller Sizing:** Estimates the required charge controller rating.
- **Design Explanations:** Provides explanations of the calculated system requirements.

## 5. Getting Started

### Prerequisites

- Python 3.11 or later.
- A computer with Python installed.

### Installation

1. Clone this repository:

   `git clone https://github.com/joymoipei3-lab/solar-mini-grid-sizing-calculator-.git`

2. Navigate to the project directory:

   `cd solar-mini-grid-sizing-calculator-`

3. Locate the Python application file.

4. Run the application:

   `python your_script_name.py`

   Replace `your_script_name.py` with the actual Python filename.

## 7. Potential Applications

The application is intended to support preliminary solar mini-grid design and provide an educational tool for understanding the relationship between electrical energy demand and solar PV system component sizing.

**Note:** The calculator provides preliminary estimates. Final system designs should consider site-specific solar irradiation, system losses, applicable engineering standards, equipment specifications and professional engineering verification.
